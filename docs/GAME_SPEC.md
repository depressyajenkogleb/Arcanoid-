# Idle Miner

## Концепция

Игрок добывает ресурсы в шахте с помощью буровых дронов.

## Платформа

- Web
- Яндекс Игры

## Стек

- HTML5
- CSS3
- Vanilla JavaScript
- Canvas 2D

## MVP

### Игровое поле

- 8 колонок
- 12 рядов

### Механика

- Игрок запускает дроны
- Дроны рикошетят
- Блоки имеют HP
- Блоки уничтожаются
- После хода появляется новый ряд

### Экономика

- Золото
- Улучшения
- Новые ресурсы

### Сохранение

- LocalStorage

### Монетизация

- Rewarded Ads
- Fullscreen Ads
